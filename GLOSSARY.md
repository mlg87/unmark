# Unmark

A lightweight macOS app for reading and editing markdown files, rendered the way GitHub renders them.

## Language

### Panes

**Preview**:
The rendered, GitHub-styled output of a document's markdown.
_Avoid_: Rendered view, reader mode, default view

**Source**:
The raw markdown text of a document.
_Avoid_: Raw, editor, plain text

**Outline**:
The sidebar listing a document's headings in order, used to jump within the Preview.
_Avoid_: TOC, table of contents, navigator, sidebar

### View modes

**Preview mode**:
The default view mode, in which a window shows only the Preview.
_Avoid_: Reader mode, rendered mode

**Split mode**:
The view mode in which a window shows the Source and Preview side by side.
_Avoid_: Two-pane mode, side-by-side, dual view, Split View (that is the macOS full-screen tiling feature)
